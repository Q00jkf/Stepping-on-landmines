# 踩地雷遊戲 - Minesweeper

這個資料夾包含兩個版本的踩地雷遊戲：Python版本和HTML版本。

## 文件說明

### 1. Python版本 - `minesweeper.py`
- 使用 tkinter 圖形界面
- 支援三種難度：初級、中級、高級
- 完整的遊戲邏輯和GUI

### 2. HTML版本 - `minesweeper.html`
- 網頁版本，可在瀏覽器中運行
- 響應式設計，支援不同螢幕大小
- 同樣支援三種難度

## 如何運行

### Python版本
1. 確保已安裝Python 3.x
2. 在命令行中執行：
   ```bash
   python minesweeper.py
   ```
3. 選擇難度開始遊戲

### HTML版本
1. 直接用瀏覽器打開 `minesweeper.html` 文件
2. 無需安裝任何額外軟件

## 遊戲規則

1. **目標**：找出所有地雷位置，避免踩到地雷
2. **操作**：
   - 左鍵點擊：揭露格子
   - 右鍵點擊：標記/取消標記地雷
3. **數字**：表示該格子周圍8個格子中地雷的數量
4. **勝利條件**：揭露所有非地雷格子
5. **失敗條件**：點擊到地雷

## 難度設置

- **初級**：9×9 網格，10個地雷
- **中級**：16×16 網格，40個地雷
- **高級**：16×30 網格，99個地雷

## 功能特色

✅ 多種難度選擇
✅ 直觀的圖形界面
✅ 右鍵標記功能
✅ 自動揭露空白區域
✅ 防止首次點擊踩雷
✅ 遊戲狀態顯示
✅ 重新開始功能
✅ 響應式設計（HTML版本）

## 技術實現

### Python版本技術棧
- Python 3.x

- random（隨機數生成）

### HTML版本技術棧
- HTML5
- CSS3
- JavaScript (ES6)

## 遊戲截圖

遊戲包含以下元素：
- 遊戲板：顯示所有格子
- 地雷計數器：顯示剩餘地雷數
- 狀態顯示：顯示遊戲進行狀態
- 重新開始按鈕：重置遊戲
